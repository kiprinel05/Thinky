# Group the Images - Asset-uri

Pune imaginile pentru misiunea "Group the Images" în subfolderele de mai jos.

## Structura așteptată

```
Grouping Dataset/
├── fruits/          ← fructe (apple.png, banana.png, etc.)
├── vegetables/      ← legume (carrot.png, broccoli.png, etc.)
└── toys/           ← jucării (ball.png, car.png, etc.)
```

## Fișiere așteptate

### fruits/
- apple.png
- banana.png
- grape.png
- orange.png
- strawberry.png

### vegetables/
- carrot.png
- broccoli.png
- tomato.png
- pepper.png
- potato.png

### toys/
- ball.png
- car.png
- doll.png
- blocks.png
- teddy.png

## Format
- Imagini PNG (sau JPG)
- Numele fișierelor trebuie să coincidă exact cu cele de mai sus
- Poți adăuga și alte imagini în fiecare categorie – actualizează `Backend/features/grouping/service.py` (ITEMS) pentru a le include
